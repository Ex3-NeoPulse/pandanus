# Pandanus — สารานุกรมใบเตยหอม

เว็บไซต์ Static สำหรับอ่านข้อมูลเบื้องต้นเกี่ยวกับเตยหอม (`Pandanus amaryllifolius`)
ทั้งลักษณะพฤกษศาสตร์ การใช้ในอาหาร และเครื่องมือคำนวณสัดส่วน

## เปิดใช้งานในเครื่อง

จากโฟลเดอร์รากของโปรเจกต์ รัน Static server:

```bash
python3 -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000/Pandanus/> ในเบราว์เซอร์
หน้าเว็บไม่มีขั้นตอน build แต่โหลด Tailwind CSS และ Google Fonts จาก CDN
จึงควรเชื่อมต่ออินเทอร์เน็ตขณะตรวจรูปแบบ

## รูปภาพ

ภาพประกอบอยู่ใน `image/` และเรียกจาก `index.html` ด้วย relative paths:

- `Gemini_Generated_Image_9ixu8u9ixu8u9ixu (1).jpeg` — กอเตยหอมในสวน
- `Gemini_Generated_Image_9ixu8u9ixu8u9ixu.jpeg` — ใบเตยสดที่เตรียมใช้ในครัว

ตรวจสิทธิ์และความเหมาะสมของไฟล์ภาพก่อนเผยแพร่สู่สาธารณะ

## ขอบเขตข้อมูลสุขภาพ

ส่วนภูมิปัญญาพื้นบ้านและงานวิจัยจัดทำเพื่อการศึกษา ไม่ใช่คำแนะนำ วินิจฉัย
หรือรักษาโรค งานอ้างอิงในหน้าเว็บประกอบด้วยบทความทบทวน งานในสัตว์ทดลอง
และการทดสอบสารสกัดในห้องปฏิบัติการ ซึ่งไม่ยืนยันประสิทธิผลทางคลินิกในมนุษย์
ไม่ควรใช้ข้อมูลนี้แทนคำแนะนำจากบุคลากรทางการแพทย์หรือปรับยาที่แพทย์สั่ง
